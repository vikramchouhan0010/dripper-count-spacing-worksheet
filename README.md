# Dripper count per acre, bay-size and spacing worksheet (orchard and polyhouse)

A worksheet for the plants-to-drippers step in a drip or fogging plan.

| Row x plant spacing | Plants per acre | Drippers per plant | Drippers per acre |
|---|---|---|---|
| 1.2 m x 0.45 m | 7,494 | 1 | 7,494 |
| 1.5 m x 0.6 m | 4,497 | 1 | 4,497 |
| 1.8 m x 0.9 m | 2,498 | 1 | 2,498 |
| 3 m x 3 m | 450 | 2 | 899 |
| 4.5 m x 4.5 m | 200 | 4 | 799 |

Plants per acre use 4,047 m2 per acre, rounded. These are example grids, not a recommendation: set yours with your agronomist.

Flow per acre = drippers x LPH. Zones keep the pump size to one zone.

For greenhouse cooling, the equivalent step is nozzle heads: a 3 m x 3 m fog grid is about 111 heads per 1,000 m2 (see https://www.blustal.com/greenhouse-fogging-system-design-guide/).
